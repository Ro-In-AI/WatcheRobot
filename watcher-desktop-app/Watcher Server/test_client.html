AI 状态同步

桌面端作为上位机时，可以直接发送 evt.ai.status 给服务端， 再由服务端转发到在线硬件端。当前支持六种固定状态：thinking、 processing、listening、 speaking、completed、 error。如需把状态和图片/动作/音效关联，可同时填写 image_name、action_file、 sound_file。

Desktop Config
配置工作台

这里直接读取服务端返回的配置报告，按模块切换当前 provider，并编辑基础/高级设置后立即应用到服务端。 这套配置会写回 JSON 文件，并切换服务端当前生效的 ASR / TTS / LLM / Dialogue 运行时，或直接热更新 Scheduler 定时任务模块。

配置工作台

只在 desktop 视角下开放。ASR / TTS / LLM / Dialogue 在硬件语音流程忙碌时会被服务端拒绝热更新； Scheduler 则支持在服务运行中直接关闭或重新开启。
